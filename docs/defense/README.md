# 《答辩问答》· 题 2《AI 学习辅助系统》

> **为什么要出这份东西**：题面第 1 页原话 ——「会对项目细节深入提问，**如果答不出细节可能会被认为过度使用 AI**」。
> 这是本题**唯一的评分门**：功能做得再全，讲不清设计决策就归零。
>
> **怎么用**：每个模块一份，结构固定三节 ——
> ① **这段代码干什么**（一句话能说清）
> ② **关键设计决策 + 为什么这么定**（表格，面试官最爱问的就是"为什么"）
> ③ **可能被追问的问题 + 你要能答的要点**（带 ⚠️ 的是我实测过容易翻车的点）
>
> 🔴 **必须先自己过一遍**。看的时候不要背句子，要盯住每一行"为什么"——
> 面试官不会按原文问，他换一个角度你还得答得出来。**过完之后，把答不顺的地方告诉我，我重写那一节。**

## 全局必答的 5 个问题（任何模块都可能被问到）

**Q1：这个项目最难的地方是什么？**
> 不是算法，是**"边界"**。三个边界最难：① 知识点**什么时候该合并、什么时候不该**（合错了不可逆）；
> ② 模型输出的**不可信**（所以每次抽取都要过 schema 校验，每条提议都要过白名单校验）；
> ③ **"资料里没有"这件事必须能被判定出来**，不能靠模型自觉 —— 我用的是数值阈值，不是提示词。

**Q2：为什么用 TypeScript 但不装框架、不装依赖？**
> 因为运行环境是别人的机器，**依赖越多越可能在评审机上跑不起来**。
> 我用 `node --experimental-strip-types` 直接跑 `.ts`，Node 自己剥类型，不需要编译步骤。
> 代价是它**不做类型检查**（所以我又加了一份只用于开发期自检的 tsconfig，见 README §10）。

**Q3：你说"零依赖"，那 `package.json` 里的 `devDependencies` 是什么？**
> 是**开发期**的 `typescript` + `@types/node`，只服务于 `npm run typecheck`。
> `dependencies` 字段是空的 ⇒ 演示、测试、部署**都不需要 `npm install`**。

**Q4：哪些地方你**没**做？**
> ① **语义合并**（用 embedding 找同义知识点）默认不做 —— 只做字符串归一化 + 别名表。
> 因为自动合并会**静默吃掉一个知识点**，不可逆；真要做也只会产出"候选对"给人确认。
> ② PDF / PPTX 不直接解析，只吃 md（要先转）。③ 不做多进程并发写的加锁。
> ④ 路 A（模型抽取）的粒度可能和真题 md 声明的粒度对不齐，会出现"真题提到、资料没覆盖"的点。

**Q5：演示里为什么第一步是"上传资料"？CLI 有上传吗？**
> 没有。**CLI 形态下说的是"把 md 放进 `data/materials/`"** —— 演示台词我会说"接入资料"，不说"上传"。
> 只有网页壳（`public/index.html`）才有真正的上传动作，走 `POST /api/upload`。
